# ONG Lar Amigo

Projeto de site desenvolvido durante meus estudos de Análise e Desenvolvimento de Sistemas, com foco na prática de HTML5 e CSS3.

## Sobre o projeto

O Lar Amigo é um site fictício voltado à adoção de animais.

O projeto possui páginas para apresentação da ONG, visualização de animais disponíveis para adoção e contato.

## Tecnologias utilizadas

- HTML5
- CSS3

## Funcionalidades

- Página inicial
- Página de adoção
- Página de contato
- Cards de animais disponíveis
- Navegação entre páginas
- Formulário de contato

## Conceitos praticados

- Estruturação semântica com HTML
- Estilização com CSS
- Organização de arquivos
- Navegação entre páginas
- Utilização de imagens
- Criação de cards
- Formulários
